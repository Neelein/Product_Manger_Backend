# Monthly filter for announcements and chat rooms

## What
Added optional `year` and `month` query parameters to the existing `GET /api/announcements` and `GET /api/chat/rooms` endpoints. When provided, results are filtered to only include records whose `created_at` falls within the specified month.

## Why
The frontend calendar needs to show announcements and chat rooms by month, similar to the events feature. Adding optional parameters (rather than separate endpoints) keeps the API surface clean.

## Changes
- New migration: `013_add_monthly_filters.up.sql` with `list_announcements_by_month`, `count_announcements_by_month`, `list_chat_rooms_by_member_by_month` (the chat room function returns only room fields, see `2026-07-25-4.md`)
- Repository interfaces: added `ListByMonth` to AnnouncementRepository, `ListRoomsByMemberByMonth` to ChatRoomRepository
- Repository implementations: added the two new methods
- Handlers: modified `ListAnnouncements` and `ListRooms` to parse optional year/month params
