# Simplify chat room monthly listing — only room fields

## What
Changed `list_chat_rooms_by_member_by_month` to return only room fields (id, name, created_by, created_at, updated_at) instead of the full ChatRoomWithMeta result set including message/unread data.

## Why
The client only needs room metadata for the monthly calendar view. The message aggregates are expensive (LATERAL joins + read_receipts) and unnecessary for this use case.

## Changes
- New migration `014_simplify_chat_room_monthly_function.up.sql` with simplified function
- Simplified `ListRoomsByMemberByMonth` scan in `chat_repo.go` to only scan room fields
