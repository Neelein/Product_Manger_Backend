# golang-time-conversion skill + event handler UTC normalization

## What
Created `.agents/skills/golang-time-conversion/SKILL.md` documenting the convention that all time.Time values from API requests must be normalized to UTC before database storage. Applied the convention to the event handler's CreateEvent and UpdateEvent methods.

## Why
Prevents timezone inconsistencies. Frontend may send times in any timezone (e.g. `+08:00`, `+05:30`), but the database stores TIMESTAMPTZ. Converting to UTC in the handler ensures consistent storage and straightforward querying.

## Key decisions
- Conversion happens in the handler layer, right after decoding the request body and before building the domain struct
- Used `.UTC()` which is idempotent (safe to call multiple times)
- Applied to both StartTime and EndTime in CreateEvent and UpdateEvent
